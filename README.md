## 🧠 Sobre o projeto

O **InvestSim** é uma aplicação web educacional desenvolvida com **HTML, CSS e JavaScript**, criada com o objetivo de transformar conceitos de investimentos e análise de perfil de risco em uma experiência interativa.

Por meio de um questionário, o sistema analisa as respostas do usuário e classifica seu perfil como:

- 🛡️ Conservador
- ⚖️ Moderado
- 🚀 Agressivo

Após a identificação do perfil, a aplicação apresenta uma **carteira ilustrativa**, gráficos de distribuição e uma projeção patrimonial baseada em valores hipotéticos.

> ⚠️ **Aviso:** este projeto possui finalidade exclusivamente educacional. Os resultados apresentados são simulados e não representam recomendação de investimento ou garantia de rentabilidade.

## 🎯 Objetivos

O projeto foi desenvolvido com os seguintes objetivos:

- Criar uma aplicação web interativa;

- Trabalhar com formulários e interação do usuário;
- Desenvolver uma classificação baseada em pontuação;
- Representar dados visualmente por meio de gráficos;
- Demonstrar conceitos de diversificação de investimentos;
- Criar uma projeção patrimonial utilizando juros compostos;

## 🚀 Funcionalidades

### 🏠 Página inicial

Apresenta o projeto e explica como funciona a simulação.

### 💰 Dados iniciais

O usuário informa:

- Valor inicial do investimento;
- Aporte mensal.

### 📝 Questionário

O sistema apresenta perguntas relacionadas a:

- Objetivos financeiros;
- Horizonte de investimento;
- Tolerância a oscilações;
- Conhecimento sobre investimentos;
- Relação com risco.

### 🎯 Identificação do perfil

As respostas recebem uma pontuação e o sistema classifica o usuário em três categorias:

| Perfil | Característica |
|---|---|
| 🛡️ Conservador | Maior foco em segurança e previsibilidade |
| ⚖️ Moderado | Equilíbrio entre segurança e crescimento |
| 🚀 Agressivo | Maior tolerância a oscilações |

### 💼 Carteira ilustrativa

Após identificar o perfil, o sistema apresenta uma possível distribuição percentual entre diferentes categorias de ativos.

### 📊 Visualização de dados

A aplicação apresenta gráficos para facilitar a interpretação das informações:

- Distribuição da carteira;
- Distribuição de risco;
- Evolução patrimonial projetada.

### 📈 Projeção patrimonial

O sistema utiliza:

- Investimento inicial;
- Aporte mensal;
- Taxa hipotética;
- Período de 10 anos;

para gerar uma projeção educacional da evolução do patrimônio.

### 🔄 Reiniciar simulação

O usuário pode realizar uma nova simulação a qualquer momento.
